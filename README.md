# Library OOP Mini

Project Library OOP Mini dibuat menggunakan bahasa pemrograman PHP.

## Fitur

- Class Book untuk mengelola data buku
- Class Member untuk mengelola data anggota
- Class DigitalBook sebagai turunan dari Book
- Simulasi peminjaman buku
- Menampilkan informasi buku dan member

## Struktur Project

- Book.php
- Member.php
- DigitalBook.php
- index.php
- README.md
- .gitignore

## Cara Menjalankan

1. Pastikan PHP sudah terinstall.
2. Simpan project di folder server lokal seperti `htdocs`.
3. Jalankan melalui browser menggunakan localhost.

Contoh:

http://localhost/library-oop-mini/
