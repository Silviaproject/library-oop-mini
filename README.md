# Library OOP Mini

Project Library OOP Mini dibuat menggunakan bahasa pemrograman PHP.

## Fitur

- Class Book untuk mengelola data buku
- Class Member untuk mengelola data anggota
- Class DigitalBook sebagai turunan dari Book
- Simulasi peminjaman buku
- Menampilkan informasi buku dan member

## Struktur Project

- Book.php
- Member.php
- DigitalBook.php
- index.php
- README.md
- .gitignore

## Cara Menjalankan

1. Pastikan PHP dan XAMPP sudah terinstall.
2. Simpan project di dalam folder `htdocs`.
3. Jalankan Apache melalui XAMPP.
4. Buka project melalui browser dengan alamat:

http://localhost/pwf/Tugas2/
